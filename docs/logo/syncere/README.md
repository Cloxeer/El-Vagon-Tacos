# Syncere logo options

Add logo image files here (PNG recommended). They appear automatically in the site editor under **Site settings → Logo**, same as the Follow icon picker.

**Naming:** Use descriptive filenames like `diamond-script-outline.png`. The picker shows a friendly label derived from the filename.

**Current options:**

- `diamond-script-outline.png` — thin outline script S with needle
- `diamond-script-black.png` — filled black script variant
- `diamond-monogram-white.png` — white ST monogram (default)

After adding a new file, refresh the editor to see it in the grid.
